# Illustration credits (app + auth screens)

All illustrations in this folder come from **unDraw** by Katerina Limpitsouni (https://undraw.co).
The unDraw license lets you use them for free, including in commercial projects, without attribution. You may not redistribute them as a competing illustration library. See https://undraw.co/license.

They were converted to React components by a one-off script. Every hard-coded color was replaced with a theme token (`--color-primary`, `--color-illus-*`, `--skin-*`), so the illustrations recolor with the brand and with light/dark mode.
